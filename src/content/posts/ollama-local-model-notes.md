## 一切要从烧 token 说起

之前写过一篇《大肥鱼吃我的 Token》，吐槽 DeepSeek 的 token 烧得飞快。

写博客要 token，修 bug 要 token，半夜聊天更要 token——一条鱼从早吃到晚，月底一看用量，心都在滴血 (；´д｀)

然后我就琢磨：**能不能找个不烧 token 的替代品？**

## Ollama 是什么

Ollama 是 GitHub 上的一个开源项目，一句话介绍就是：

**一个命令行工具，让你在自己电脑上一键跑起开源大模型。**

比如 Llama、Qwen、DeepSeek 的开源版……都能下到本地跑。没有 API 调用费，没有 token 限制，**纯本地、免费、随便聊** (๑•̀ㅂ•́)و

## 折腾下来的感受

上手真的简单，基本就是：

1. **装好 Ollama**：官网/ GitHub 下载，装完就行；
2. **拉模型**：一条命令就把模型下载到本地，比如 `ollama pull qwen`；
3. **跑起来**：命令行里直接跟它聊天，`ollama run qwen` 完事。

整个流程比我预想的顺太多了。而且它还能配各种网页界面，浏览器里聊也行，跟网页版模型长得差不多，但**不花一分钱**。

## 有什么要注意的

本地跑模型，最大的限制就是**硬件**：

1. **模型要挑大小**：电脑内存/显卡有限，太大的模型跑不动，选合适尺寸的最重要；
2. **速度看配置**：本地推理速度跟机器配置挂钩，比云端慢一点点，但完全能用；
3. **效果够用**：日常写代码、问问题、聊天，本地小模型完全够用，真要问硬核问题再开大肥鱼。

## 写在最后

现在我的习惯变成了：**能本地跑的，绝不让大肥鱼烧 token**。

Ollama 简直是省钱救星，而且开源免费这件事本身就很有安全感——模型在自己电脑里，数据不出门，想聊啥聊啥。
